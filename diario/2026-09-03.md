# Diário — 03/09/2026

## Exercício: construam o laço

O objetivo foi construir um agente pequeno usando **function calling**, com duas ferramentas em Python e um laço limitado por `MAX_PASSOS`. Também foi preparado um experimento para observar quanto a descrição de uma tool influencia a escolha do modelo.

## Implementação

Foram criadas duas tools em `agente.py`:

- `nome_disciplina()`: não recebe parâmetros e retorna o nome da disciplina;
- `consultar_texto(texto)`: recebe um texto e retorna a quantidade de caracteres.

As duas funções possuem docstrings e também são declaradas explicitamente no formato de function calling esperado pelo Ollama.

A pergunta usada nos dois casos é a mesma:

> Use uma ferramenta para responder: quantos caracteres existem na palavra "agente"?

O laço envia a pergunta ao modelo, executa a tool solicitada, devolve o resultado como mensagem de `tool` e repete o processo até o modelo responder sem novas chamadas ou até atingir `MAX_PASSOS`.

## Experimento com a descrição da tool

Foram preparados dois cenários:

1. **Descrição clara:** `consultar_texto` é apresentada como uma ferramenta que conta quantos caracteres existem no texto informado.
2. **Descrição vaga:** a mesma tool mantém nome, parâmetros e implementação, mas sua descrição no schema é substituída por `"faz uma consulta"`.

Assim, a implementação permanece a mesma e a principal variável modificada no experimento é a descrição apresentada ao modelo.

## Observação

O experimento permite verificar se uma descrição pouco informativa aumenta o número de passos, faz o modelo escolher a tool errada primeiro ou impede a escolha da ferramenta adequada. O resultado não deve ser presumido: ele depende do modelo utilizado e deve ser registrado a partir de uma execução real.
